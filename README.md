# DCF Valuation Model | Discounted Cash Flow Analysis

## 📊 Project Overview

This project presents a Discounted Cash Flow (DCF) valuation model developed in Microsoft Excel to estimate a company's intrinsic value using projected unlevered free cash flows.

## 🎯 Key Areas

- Revenue and free cash flow forecasting
- Net working capital and fixed asset schedules
- Weighted Average Cost of Capital (WACC)
- Terminal value and enterprise value calculation
- Implied share price and sensitivity analysis

## 🛠️ Tools & Techniques

- Microsoft Excel
- DCF Valuation
- Financial Modeling
- Financial Statement Analysis
- Sensitivity Analysis

## 📁 Repository Structure

- `DCF_Valuation_Model_Protected.xlsx` — Protected Excel model
- `screenshots/` — Model outputs and supporting schedules

## 📌 Notes

- This is an independent financial modeling project for educational and portfolio demonstration purposes.
- Figures and assumptions should be reviewed before use in any investment decision.
